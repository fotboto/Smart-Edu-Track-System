# Smart-Edu-Track-System
Smart Edu Track System is a Django-based academic portal designed to streamline student performance tracking, communication, and personalized learning through AI-powered recommendations. It enables teachers, students, and parents to interact seamlessly while offering real-time academic analytics and actionable insights.
