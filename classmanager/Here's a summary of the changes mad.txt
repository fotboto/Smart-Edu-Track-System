# Core Libraries in AI Recommendation System

Here's a short explanation of the key libraries and their roles:

### Data Analysis and AI Components
- **pandas (v2.0.3)**: Handles data manipulation for student marks, creating DataFrames for efficient analysis of academic performance patterns
- **numpy (v1.24.3)**: Performs numerical operations like percentage calculations and statistical analysis of student performance
- **scikit-learn (v1.3.0)**: Powers the recommendation algorithms, particularly for pattern matching and scoring career compatibility
- **matplotlib (v3.7.2)**: Generates performance visualizations in the student dashboard, showing subject strengths and weaknesses

### Web Framework and Frontend
- **Django (v2.2.12)**: Core web framework that handles routing, database models, and view logic
- **django-bootstrap4 (v1.1.1)**: Provides responsive UI components for displaying recommendations
- **django-misaka (v0.2.1)** and **misaka (v2.1.1)**: Handles text formatting for resource and career descriptions

### Supporting Libraries
- **scipy (v1.11.1)**: Supports advanced statistical operations for the recommendation engine
- **joblib (v1.3.1)**: Handles efficient parallel processing of recommendation calculations

The system combines these libraries to:
1. Extract and analyze student performance data (pandas, numpy)
2. Apply recommendation algorithms to identify appropriate resources and careers (scikit-learn)
3. Present the recommendations through a user-friendly web interface (Django, Bootstrap)
4. Visualize performance metrics to help students understand their strengths (matplotlib)

This integrated approach creates a personalized learning guidance system without requiring complex machine learning infrastructure.
